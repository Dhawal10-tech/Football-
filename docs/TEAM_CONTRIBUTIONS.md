# Suggested Four-Member Contribution Plan

This is a suggested allocation, not a claim about actual contributors or completed work. Replace the role labels with real names only after the team agrees.

| Member | Suggested responsibilities |
|---|---|
| Member 1 | Domain records, IDs, team/player validation and model documentation |
| Member 2 | Fixture generation, standings, result handling, winner/tie policy and algorithm tests |
| Member 3 | SFML layout, navigation, forms, tables, dialogs, resize behavior and GUI manual tests |
| Member 4 | File repository, scorer statistics, history/reports, integration and documentation |

All members should review interfaces, integrate changes together, run the documented test suite, and record actual contributions before submission.
